1 Overview / 概述

The UFL-1A module is a flow sensing module based on ultrasonic flow sensing technology. The key components are manufactured in an integrated manner, with small size and low cost, which can replace the current traditional Hall sensor flow solution.

UFL-1A模块是一款基于超声波流量传感技术的流量传感模块，关键部件采用一体化制造，体积小、成本低，能取代目前传统的霍尔传感器流量解决方案。

6 UART function / UART 功能

UART format: baud rate 2400 bit/s, 8-bit data, 1 stop bit, 1 even parity check bit.

UART基本格式：波特率 2400bit/s，8 位数据，1 个停止位，1 个偶校验。

When multi byte data is sent, low bytes are sent first and are represented in decimal. After receiving the command, UFL-1A should first send the response symbol “0xe5” and then reply to the data according to the command requirements.

多字节数据时低字节先发，均以十进制表示。UFL-1A 收到命令后应先发送应答符“0xe5”，再按命令要求回复数据。
