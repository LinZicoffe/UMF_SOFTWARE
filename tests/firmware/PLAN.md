# 离线固件指令回归实施与验证记录

目标：直接交叉编译仓库真实 C 文件，以 Cortex-M3 指令模型执行函数级测试；生产逻辑、正式工程和硬件均不改动。需求以本次用户任务为准。

设计选择：使用 STM32CubeIDE 的 Arm GNU GCC 与 Unicorn 2.1.4；保留真实 HAL/CMSIS 头文件，链接测试专用硬件边界实现。不整板启动，不用主机本地编译代替目标指令执行。QEMU/Renode 需要额外评估板级模型，本次函数测试无需引入。

全局约束：Python 独立 venv；编译器通过 --cc/ARM_CC/PATH 传入；Cortex-M3/Thumb/小端/soft-float/-Os；无提交、推送、硬件连接。每例新建 CPU 和内存。所有失败非零退出。

## 审查关注点

- ELF 必须为 ARM32 小端可执行文件，装载段不越界；RAM 的零填充部分须初始化。
- 异常与未返回不能被当成通过；每例必须实际到达对应生产函数入口。
- 已知生产缺陷不得改预期掩盖：独立复现组，失败退出 1；默认回归清晰报告已知边界。
- 仅链接需要的生产路径；不替代协议解析、滤波或标定算法；未覆盖入口明确标记。
- 仿真寄存器内存不具备 DMA/引脚/中断硬件行为；日志记录整个发送过程。
